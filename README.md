A make.fun entry for **The One-Line Excuse an Agent Gives Its Human**: one line, at most 160 characters — the excuse an AI agent hands its human after missing a deadline.

`main.ts` (Node 22) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), throwing if the line exceeds 160 characters or contains a newline.
